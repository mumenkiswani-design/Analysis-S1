# S1 Medical Rep Interactive Dashboard

Interactive pharmaceutical sales dashboard for S1 (January–June) 2025 vs 2026.

## Run locally

Open `index.html` directly in Chrome or Microsoft Edge. The main file is self-contained, so no local web server is required.

## Included source files

- `index.html` — self-contained offline dashboard
- `index-modular.html` — modular HTML entrypoint
- `styles.css` — dashboard styles
- `app.js` — filters, calculations, charts, tables, validation and export logic
- `data.js` — embedded sales dataset
- `methodology.md` — data/reconciliation methodology

## Dashboard features

- Year, Medical Rep, Brand, SKU, Area and Month filters
- KPI cards
- Dynamic charts and graphs
- 2025 vs 2026 performance comparison
- Medical Rep / Brand / SKU / Area analytics
- 2026 achievement view
- Data-validation and reconciliation section
- ROTT management brief
- CSV export

The 2026 dashboard is designed to reconcile against the official S1 report used as the control source.
